# MazeBall

MazeBall is a simple mobile game for Android devices created in Kotlin.  
The goal of the game is to control a ball inside a maze and guide it to the finish square.

## Requirements
- Android 8.0 (Oreo) or newer
- Android Studio installed

## Installation
1. Clone the repository:
git clone https://github.com/MaciekPie/MazeBall.git
3. Open the project in Android Studio
4. Build and run on:
 - Android emulator,
 - Physical Android device

## Features
- Maze navigation gameplay
- Ball physics movement
- Simple and clean UI
- Built entirely in Kotlin
